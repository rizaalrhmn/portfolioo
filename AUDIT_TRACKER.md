## What the live site really looks like (checked 28 Nov 2026)
The audit's main claim, that the site is inaccessible and can't be crawled, **is out of date.**
`https://rizalrhmn.vercel.app/` returns **HTTP 200** with no `x-robots-tag: noindex` header.
The page is static HTML, not an empty React `<div id="root">`. The title and `<h1>` already
contain “Freelance Digital Marketing in Malta”. These are the real problems I found:

| Problem found | Fix |
|---|---|
| `/robots.txt` → 404 | CODE: generated by `build-seo.mjs` |
| `/sitemap.xml` → 404 | CODE: generated, with lastmod |
| Blog posts only exist in JavaScript (loaded from Supabase into a modal at `?article=`), so crawlers never see the article text | CODE: every post is pre-rendered to `/insights/<slug>/`, and old `?article=` links get a 308 redirect |
| Blog cover images stored as base64 inside the database | CODE: extracted to `/images/blog/*.png` · AG: upload future covers to Storage |
